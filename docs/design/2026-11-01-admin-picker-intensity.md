# 后台素材选择与动效强度优化

用户已委托按现有设计直接优化。本轮保留现有后台结构、海蓝灰底色、9px 主按钮圆角与四个主操作的动效范围。

1. 网站图标与封面采用当前选择预览和更换入口；行内展开搜索/图库/上传，选中后收起并返回触发器。Escape 先收起当前选择区，保留父弹窗。Logo 保持现有独立配置。
2. 四个主操作增强边缘追光、局部光池、一次扫光以及轻微悬停/按下反馈。静态外观仍沿用原按钮，禁用、触屏和减少动态效果不播放装饰动画。
3. 页面氛围增加轻柔、适中、浓郁三档，桌面分别8/16/32，手机4/8/16。旧配置默认适中，关闭氛围时保留档位。存储、校验、导入导出与首页渲染使用同一份预设。

核对折叠/展开、键盘选择与焦点返回、素材保存、手机布局；验证强度保存及刷新保留、首页数量变化和旧配置兼容。使用隔离测试数据，远程更新前在线备份并逐表核对正式数据。结束后停止本地服务，清理临时文件，不提交或推送 Git。
