# 素材独立选择框

用户已确认以下交互并授权实现：网站编辑弹窗仅显示当前图标和封面；点击更换打开独立选择框。选择框含待确认预览、素材列表及取消/确认选择。点击素材不回写网站表单，明确确认后才更新预览；取消、关闭或Escape放弃本次草稿。最终仍需保存网站。

素材选择复用项目Radix Dialog，置于网站编辑器上方；封面裁剪位于选择框上方，取消或上传成功均回到选择框，上传成功仅更新待确认封面。选择框关闭后焦点回到对应更换按钮。Logo保留既有单独配置流程。

按用户补充要求，后台通用弹窗、素材框与裁剪框点击遮罩均保持打开，防止误点丢失填写内容。明确关闭、取消和Escape仍保留。

标题与底部操作固定，素材区域内部滚动；手机采用两列封面、六列图标。沿用海蓝灰、原按钮和既有动效范围，不新增依赖。
