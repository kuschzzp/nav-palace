# React Bits 动效适配

按用户指定的三个效果更新现有导航站，保留海蓝灰、樱花色点缀、动漫海报卡片、入口优先布局及原有管理流程。

- 按用户纠正后的范围，仅后台“添加网站、保存站点设置、更新密码、保存网站”四个主操作叠加双瓣边缘高光和随鼠标移动的内反光。原有底色、文字色、9px 圆角、尺寸与布局全部保留。首页按钮、后台菜单、标签、开关及其余操作恢复原样式。共享事件委托与按需动画，不为每个按钮创建 WebGL 上下文。
- 首页主标题采用 Tech Text 的局部虚线字形、定位角和扫描细节。真实中文文字保留在 DOM 中，浏览器负责换行；仅互动时使用 Canvas 增强。
- 首页及跳转页使用 Gradient Waves 的真实 WebGL2 波浪，沿用官方 shader，调整为缓慢的海蓝、雾蓝和少量柔粉反光。透明装饰层不阻拦入口操作。
- 删除背景图片、后台背景选择/上传、默认图库、预处理逻辑和公开配置字段；v5 迁移仅清除旧字段。网站封面、Logo、头像及历史 QA 截图保留其原用途。
- 暂停按钮控制波浪、漂浮与标题增强；隐藏标签页、减少动态效果、触屏和不支持 WebGL 时采用相应静态显示并清理动画资源。

验证覆盖真实渲染、鼠标追光、中文标题响应、四个主操作的范围隔离、禁用与键盘操作、暂停恢复、移动布局、旧数据迁移和背景资源清理。部署前备份现有数据库，复用持久化卷；不更换管理员与私密访问凭据。
